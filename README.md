## Featured projects

### [AI Data QA for BigQuery](https://github.com/YevheniiDyachenko/Ai-Data-QA)

Lightweight AI-assisted tool for automated data quality validation in Google BigQuery.

- Schema discovery for BigQuery datasets and tables
- Data profiling: row counts, null counts, distinct counts
- AI-generated SQL quality tests with strict JSON contracts
- SQL safety validation for `SELECT`-only execution
- CLI workflow and FastAPI-backed control panel
- JSON / Markdown reports and trend history

### [Last-Tale-2D](https://github.com/YevheniiDyachenko/Last-Tale-2D)

2D top-down action prototype built with Unity.

- Two playable animal characters
- Preparation phase with traps and resources
- Boss fight with staged behavior
- Player abilities, game flow managers, UI, and gameplay systems

### [JSON Comparator](https://github.com/YevheniiDyachenko/json-comparator)

Utility-oriented project for comparing structured JSON data.  
Useful for data validation, API testing, and QA workflows.
